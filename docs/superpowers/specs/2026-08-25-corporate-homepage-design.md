# 普通企业官网首页设计

## 目标

保留现有深色工业视觉系统，把首页改为常规企业官网信息架构，解决首屏右侧空白和内容过度拉长的问题；同时删除浏览器标签页中的“鼎”字 favicon。

## 首页结构

- 使用单屏静态 Hero，桌面高度约 620px，不使用五幕、长滚动、Canvas、视频或帧序列。
- 左侧为公司定位、简介和两个 CTA；右侧使用真实业务照片 `assets/img/hero-helium.jpg`。
- 图片边缘以深色渐变与文字区融合，保持现有石墨黑、钢灰、铜色标签和青绿色 CTA。
- Hero 下方直接进入现有主营业务、品牌、项目案例和联系区块，不重复讲解五幕内容。
- 移动端 Hero 自然堆叠，图片位于文字下方，避免裁切文字和横向溢出。

## 浏览器图标

- 七个页面统一使用空 favicon 声明，浏览器标签页不再显示“鼎”字图标。
- `favicon.ico`、`assets/favicon.svg` 与 `assets/apple-touch-icon.png` 保留为历史源码，但不进入 `_site`，避免浏览器自动回退请求旧图标。
- 页面 `<title>` 保留正常公司与页面名称，保证可访问性和搜索识别。

## 验证

- 静态契约确认首页只有一个企业 Hero、引用真实横图、无五幕/Canvas/动态运行时。
- 构建契约确认旧图标和动态动画资源均不进入发布产物。
- Playwright 验证桌面与手机 Hero 布局、无横向溢出、无动态资源请求、空 favicon 和控制台无错误。
